# Rightnest icon brief

Audience: people accustomed to Windows window controls, using a small native Mac utility.
Traits: quiet, precise, familiar, dependable. Menu-bar mark must work at 16 points.
Use: macOS app icon, menu bar, README. No house/bird imagery despite the name; no three traffic-light circles or generic arrow.
A: abstract corner, a separate upper-right block seated in an open frame. Recommended: communicates location without drawing controls.
B: constructed R letterform. Familiar but less distinctive at small sizes.
C: abstract cradle. Strong silhouette but weaker connection to the right side.
Black-first concepts; no final icon until the direction is selected. Reference library studied for geometry only; no library artwork included.
Name search: Starboard collides with palamim/starboard (macOS terminal). User selected Rightnest. Search also found unrelated RightNest iOS/property and childcare uses; this is not a uniqueness or trademark clearance claim.
